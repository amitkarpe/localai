GO for day-1 build

Primary model: qwen2.5:1.5b-instruct

Fallback: no automatic API fallback. If local path fails, stop and re-rank (manual approval required).

Why this model was chosen

  • Small enough for low-resource local usage, while still passing all three fixed prompts.
  • Single-model lock keeps integration low risk and aligns with 80% useful outcome target.
  • Model metadata and artifacts can be hosted on local storage (/mnt/ai) after configuration.
  • No hard blocker from runtime quality for day-1 envelope.

Fallback model path remains disabled by policy; if this model ever fails hard, re-open with explicit approval.
